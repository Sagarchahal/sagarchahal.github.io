# GitHub and hackathon submission checklist

## Publish the project on GitHub

1. Sign in to GitHub and create a **new public repository** named `agentbiz-ai` (or another name you prefer). Do not initialize it with extra files if you will upload the existing folder.
2. In the repository, choose **Add file → Upload files**.
3. Upload the contents of the `AgentBizAI` folder: `index.html`, `style.css`, `script.js`, `README.md`, `DEMO_SCRIPT.md`, and `GITHUB_SUBMISSION.md`.
4. Enter a commit message such as `Add AgentBiz AI prototype and submission guide`, then commit the files.
5. Open `index.html` in the repository to confirm it is present.
6. For a public demo website, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Wait for GitHub Pages to publish and test the generated URL in a private/incognito window. If the page does not work, check that all three asset files are in the same published folder and filenames match exactly.
7. Record a 60–90 second screen demo using `DEMO_SCRIPT.md`. Upload it to a platform permitted by the hackathon and use the shareable video URL only after testing it in a signed-out/private window.
8. In the Devpost submission, paste the real repository URL, the working live demo URL if deployed, and the real demo-video URL. Never invent links or claim deployment before testing it.

## Before clicking Submit

- [ ] Read the hackathon's eligibility, deadline, submission format and judging criteria on the official event page.
- [ ] Confirm the event accepts a web prototype and that your project matches its rules.
- [ ] Confirm every link opens without requiring your personal login.
- [ ] Use screenshots/video of the actual running project.
- [ ] Explain that checkout is simulated and the workflow uses local templates.
- [ ] Do not include API keys, passwords, private customer data or payment details in the repository.
- [ ] Do not claim real revenue or real AI autonomy unless you have verifiable evidence.

## Suggested submission description

**AgentBiz AI — A prototype for an agent-coordinated digital service studio**

AgentBiz AI demonstrates a proposed small-business service workflow: a customer submits a sample brief, reviews an illustrative quote, and sees a four-role workflow produce a downloadable draft and quality checklist. It also includes a sandbox checkout that records a clearly labeled simulated event only; it does not accept money. The project currently runs in the browser using local JavaScript templates and local storage. The next phase is a secure backend, live AI integration, human approval, and verified payment integration.

**Current limitations:** no live AI model, backend, authentication, real payment processing, paying customers or verified revenue.
